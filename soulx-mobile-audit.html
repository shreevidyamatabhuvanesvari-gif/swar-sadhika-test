ॐ Swar-Sadhika — Mobile Runtime Audit

Android ब्राउज़र की वास्तविक क्षमता जाँचें — कंप्यूटर की आवश्यकता नहीं।

यह परीक्षण क्या करेगा? WebGPU का छोटा वास्तविक compute कार्य, WebAssembly, साझा WASM memory की उपलब्धता, device/memory संकेतक, local storage और audio/browser APIs की जाँच करेगा। रिपोर्ट इसी डिवाइस पर बनेगी।
महत्वपूर्ण सीमा: यह पृष्ठ SoulX-Singer का checkpoint डाउनलोड या चलाता नहीं है। इसलिए यह ONNX export, ONNX operator compatibility, AI inference, संस्कृत उच्चारण या गायन को PASS घोषित नहीं कर सकता। उसके लिए वास्तविक exported model का परीक्षण अलग से आवश्यक है।

परीक्षण अभी नहीं चला है। शुरू करने के लिए ऊपर बटन दबाएँ।

यह पृष्ठ कोई बाहरी AI API इस्तेमाल नहीं करता, कोई model file नहीं डाउनलोड करता और किसी server को रिपोर्ट नहीं भेजता।

परीक्षण परिणाम

हर परिणाम इस browser session से लिया जाएगा। जहाँ browser जानकारी उपलब्ध नहीं कराता, वहाँ उसे अनुमान से भरने के बजाय “जानकारी उपलब्ध नहीं” लिखा जाएगा।

  • अभी कोई परिणाम नहीं
    परीक्षण चलाने के बाद परिणाम यहाँ आएँगे।

अगला प्रमाण-आधारित निर्णय

डिवाइस का WebGPU उपलब्ध होना पर्याप्त नहीं है। आगे बढ़ने के लिए सभी बातें अलग-अलग सिद्ध करनी होंगी:

  1. आधिकारिक SoulX-Singer checkpoint और संबंधित model code सफलतापूर्वक load हों।
  2. Model के वास्तविक tensor inputs/outputs पहचाने जाएँ और ONNX export सफल हो।
  3. ONNX model की ONNX Runtime Web validation तथा target execution-provider operator checks पास हों।
  4. इस Android browser में वही model load होकर वास्तविक inference करे और निकला audio decode/play हो।
  5. संस्कृत phoneme/मात्रा mapping, prompt audio, melody/score inputs तथा महिला स्वर की गुणवत्ता अलग से जाँची जाए।

मौजूदा रिपोर्ट केवल डिवाइस/browser क्षमताओं का प्रमाण है; यह अंतिम model compatibility verdict नहीं है।

मशीन-पठनीय रिपोर्ट

रिपोर्ट को यहाँ देखकर कॉपी कर सकती हैं या JSON फाइल डाउनलोड कर सकती हैं। इसे साझा करने से पहले browser/device विवरण देखने का विकल्प आपके पास है।
