Android Chrome में वास्तविक WASM ONNX मॉडल-सत्र जाँच

इस परीक्षण का उद्देश्य

यह पृष्ठ Vāgdhenu के तीन वास्तविक ONNX मॉडल-सत्रों को एक-एक करके खोलने की कोशिश करता है। यह runtime द्वारा मॉडल graph पढ़े जाने, session बनाने और input/output metadata प्राप्त होने का प्रमाण देगा।

सावधानी: कुल मॉडल लगभग 275 MB हैं। परीक्षण तभी शुरू करें जब इंटरनेट स्थिर हो, बैटरी पर्याप्त हो और फ़ोन गर्म न हो। पृष्ठ अपने-आप मॉडल डाउनलोड नहीं करता; डाउनलोड परीक्षण बटन दबाने पर ही शुरू होगा।

HTTPS: जाँच… WebAssembly: जाँच… WebGPU: जाँच… CPU threads: जाँच…

मॉडल सत्र जाँच

Android पर पहले WASM SIMD backend जाँचा जाएगा। हर session की जाँच पूरी होने पर उसे release किया जाएगा; तीनों बड़े sessions एकसाथ नहीं रखे जाएँगे। ONNX Runtime और model files इंटरनेट से लोड होते हैं, लेकिन इस पृष्ठ में कोई inference server या AI API उपयोग नहीं होता।

परिणाम को कैसे समझें

तीनों session पास: यह संकेत है कि इस ब्राउज़र में ONNX Runtime इन मॉडल graphs को लोड कर सका। यह अभी पूर्ण inference, संस्कृत उच्चारण, धुन, ध्वनि-गुणवत्ता या स्त्री-स्वर की पुष्टि नहीं है।

कोई session विफल: विवरण में CORS/network, WASM operator, memory या runtime की त्रुटि दिख सकती है। एक असफल मॉडल पर पूरा ऐप अनुमान से आगे नहीं बढ़ाया जाएगा।

यह परीक्षण किसी ऐप फ़ाइल को नहीं बदलता और न vagdhenu-onnx.js बनाता है। यह उसी इंजन को सुरक्षित रूप से जोड़ने से पहले की रनटाइम-संगतता जाँच है।
