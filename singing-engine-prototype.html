GitHub Pages WebGPU / WASM स्थानीय inference

1. परीक्षण की जानकारी

यह Vāgdhenu के browser inference implementation का प्रारम्भिक एकीकरण है। मॉडल संस्कृत श्लोक की मीटर-आधारित चैंटिंग के लिए बनाया गया है। यह अभी सामान्य स्त्री-स्वर वाली AI गायिका का विकल्प नहीं है।

पहली बार मॉडल लोड करने के लिए इंटरनेट आवश्यक है। मॉडल सामग्री Hugging Face से और JavaScript runtime CDN से लोड होती है। पाठ inference के लिए किसी AI API को नहीं भेजा जाता।

2. संस्कृत पाठ

प्रारम्भ में एक छोटा, गैर-वैदिक संस्कृत श्लोक आज़माएँ। यह परीक्षण अभी लंबे पाठ, सभी वैदिक ऋचाओं या हर प्रकार के मंत्र की शुद्धता प्रमाणित नहीं करता।

3. मॉडल और inference की स्थिति

अभी मॉडल लोड नहीं हुआ है। परीक्षण शुरू करने पर मॉडल डाउनलोड और प्रारम्भ होगा।

4. उत्पन्न ऑडियो

उत्पन्न WAV ऑडियो डाउनलोड करें

ऑडियो उत्पन्न होने पर यहाँ प्लेयर दिखाई देगा।

5. परीक्षण की सीमा

वास्तविक ऑडियो सफलतापूर्वक बनना यह सिद्ध करेगा कि यह संस्कृत चैंट मॉडल इस ब्राउज़र में चला। इससे यह सिद्ध नहीं होगा कि मॉडल स्वाभाविक स्त्री-स्वर में स्वतंत्र धुन वाला गायन कर सकता है। उस लक्ष्य के लिए अलग singing-synthesis मॉडल आवश्यक है।
