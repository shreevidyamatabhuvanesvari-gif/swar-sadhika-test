1. आधिकारिक मॉडल की जानकारी

परीक्षण उम्मीदवार: SoulX-Singer (singing voice synthesis / SVS)

प्रारम्भिक निष्कर्ष: आधिकारिक PyTorch मॉडल को सीधे GitHub Pages के JavaScript पेज पर चलाने का सत्यापित तरीका उपलब्ध नहीं है। WebGPU के लिए उपयुक्त परिवर्तित मॉडल और inference implementation की जाँच आवश्यक है।
  • मुख्य गायन checkpoint: model.pt — लगभग 2.82 GB
  • पूरा SoulX-Singer पैकेज: लगभग 5.61 GB; इसमें SVS और SVC दोनों checkpoints शामिल हैं।
  • अलग preprocessing model repository: लगभग 6.92 GB
  • आधिकारिक निर्देश Python वातावरण, निर्भरताएँ और अलग से डाउनलोड किए गए pretrained models बताते हैं।
  • प्रकाशित model metadata में अंग्रेज़ी और चीनी सूचीबद्ध हैं। संस्कृत समर्थन का आधिकारिक प्रमाण अभी नहीं मिला है।

आधिकारिक स्रोत: SoulX-Singer GitHub · SVS model files · Preprocessing models

      checkpoint या converted model डाउनलोड किया हो। फ़ाइलें
      ब्राउज़र में ही पढ़ी जाएँगी; कोई अपलोड नहीं होगा।

4. अभी कौन-सी बाधाएँ हैं?


    
    
      
  • 
        मॉडल प्रारूप:
        आधिकारिक checkpoint .pt है। यह फ़ाइल WebGPU को सीधे
        executable neural network के रूप में उपलब्ध नहीं कराती।
      
    • 
      
  • 
        बड़े tensors:
        आपके पिछले परीक्षण में यदि
        maxStorageBufferBindingSize = 134217728
        आया था, तो यह 128 MiB है, 1.34 GB नहीं। पूरे 2.82 GB
        checkpoint को एक ही storage buffer में रखने की सीमा इससे
        बहुत कम है। मॉडल को बदलने, shards में रखने या अलग runtime
        तकनीक की जरूरत पड़ सकती है।
      
    • 
      
  • 
        संस्कृत:
        checkpoint का आकार या GPU का सफल होना यह सिद्ध नहीं करता
        कि मॉडल संस्कृत शब्दों का सही उच्चारण या गायन कर सकेगा।
      
    • 
      
  • 
        Preprocessing:
        आधिकारिक inference प्रक्रिया metadata और अतिरिक्त
        preprocessing का उपयोग करती है। ब्राउज़र में उसकी
        निर्भरताओं का विकल्प अभी सत्यापित नहीं है।
